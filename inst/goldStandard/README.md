The gold standard for each concept set consists of two files:

- Intersection file (e.g. C01_SLE_Gold_Standard_1.csv) lists the concepts that all AI systems and the humans agreed on should be in the concept set. These were assumed to be correct without further adjudication.
- Adjudicated file (e.g. C01_SLE_for_adjudication.xlsx) lists the concepts that not everyone agreed on, and were adjudicated by blinded experts.
